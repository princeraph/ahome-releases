Lien incomplet

Ce lien d’invitation est incomplet ou abîmé : il a peut-être été coupé en le copiant.

Demandez à la personne qui vous a invité·e de vous renvoyer le lien, puis ouvrez-le en entier.

Trois étapes

  1. Télécharger et installer Ahome

    Déjà installée sur cet ordinateur ? Passez à l’étape 2.

    Télécharger Ahome pour Windows

    L’installateur n’est pas signé. Si Windows affiche « Windows a protégé votre ordinateur » : Informations complémentaires, puis Exécuter quand même. Windows 10 ou 11, 64 bits.

  2. Ouvrir l’invitation dans Ahome

    Votre navigateur demandera peut-être d’ouvrir Ahome : acceptez. Ahome s’ouvre sur « Rejoindre un foyer », le lien déjà rempli ; rien n’est envoyé avant que vous continuiez.

    Ouvrir dans Ahome

  3. Si rien ne s’ouvre

    Copiez le lien, ouvrez Ahome, choisissez « Rejoindre un foyer », puis collez-le.

Ensuite, dans Ahome : votre prénom, votre propre phrase de récupération, puis un code à 6 chiffres à lire à la personne qui vous a invité·e.
