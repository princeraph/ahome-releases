Télécharger Ahome pour Windows

Toujours la dernière version. Une fois installée, Ahome se met à jour toute seule : elle vous propose de redémarrer quand une nouvelle version est prête.

L’installateur n’est pas signé. Windows affichera peut-être « Windows a protégé votre ordinateur ». Cliquez alors sur Informations complémentaires, puis sur Exécuter quand même.

Vous avez reçu une invitation ?

Ouvrez le lien reçu : la page vous guide pour installer Ahome, puis rejoindre le foyer.

Configuration requise

  • Windows 10 ou Windows 11, 64 bits (x64)
  • Environ 400 Mo d’espace libre
  • Une connexion Internet pour la synchronisation du foyer et les mises à jour
